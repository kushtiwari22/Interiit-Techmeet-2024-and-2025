#  Signal Generation and Trading Decisions using deterministic algorithms 

## Overview

This repository hosts an implementation of a deterministic algorithm using a group of different technical and stochastic indicators for predicting stock close prices movement Open-High-Low-Close-Volume (OHLCV) data from 2018 to 2022. Leveraging strong entry and exit conditions has a tendency to create only profitable trades.
